# 🍛 DORMZ

**DORMZ** is a modern, fast, and fully functional Android application designed to make mess/hostel management easier than ever. Built with React, Vite, and Capacitor, this app offers a seamless experience for managing daily meals, expenses, and members in a mess.

![Framework](https://img.shields.io/badge/Framework-React%20%2B%20Vite-61DAFB)
![Build](https://img.shields.io/badge/Build-GitHub%20Actions-2088FF)

## ✨ Features
* **Modern UI/UX:** A clean and intuitive interface built with React and styled beautifully.
* **Meal Management:** Easily track and manage daily meals for all mess members.
* **Expense Tracking:** Keep a transparent record of all daily and monthly expenses.
* **Member Dashboard:** Individual dashboards for members to view their deposits, meal counts, and due balances.
* **Cross-Platform Ready:** Built as a web application and natively converted to an Android APK using Capacitor.
* **Auto-Update System:** The Android APK is automatically built and released using GitHub Actions CI/CD pipelines!
